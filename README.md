## About

A minimal, high-performance portfolio site for **Sparsh Sharma** — a self-taught full-stack developer from Bangalore, India. The entire site is hand-coded with vanilla HTML, CSS, and JavaScript. No React, no build tools, no dependencies.

### ✨ Features

- **Orbital hero animation** — CSS-only animated rings with mouse-parallax
- **Scroll-reveal system** — IntersectionObserver-based entrance animations
- **Noise grain texture** — subtle film grain overlay for depth
- **Scroll progress bar** — live reading progress indicator
- **Responsive navigation** — collapsible burger menu with smooth scroll
- **Print-ready resume** — A4-optimized HTML resume page with "Save as PDF"
- **SEO-hardened** — Open Graph, Twitter Cards, JSON-LD structured data, sitemap, robots.txt
- **Zero dependencies** — no npm, no build step, just open `index.html`

## Run Locally

No install needed. Just clone and open:

```bash
git clone https://github.com/sparshsharma-dev/portfolio.git
cd portfolio
# open index.html in your browser — that's it
```

Or use a local server:

```bash
npx serve .
```
